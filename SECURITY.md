# Security Policy

The operational security guide lives in [docs/SECURITY.md](./docs/SECURITY.md).

If you discover a vulnerability in encryption, key handling, index integrity, or IPFS interaction:

1. Do not open a public GitHub issue.
2. Email the maintainer at netzuleando@gmail.com with reproduction details, affected versions, and impact.
3. Allow time for triage and coordinated disclosure before publishing details.
