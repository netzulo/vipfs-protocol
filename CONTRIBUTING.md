# Contributing to VIPFS Protocol

The full contributor guide lives in [docs/CONTRIBUTING.md](./docs/CONTRIBUTING.md).

Use this repository workflow as the default:

1. Open or link an issue before major work.
2. Keep changes scoped to one behavior, refactor, or documentation topic.
3. Run `yarn lint` and `yarn test` before opening a pull request.
4. Describe any IPFS, encryption, or wallet-related behavior changes explicitly in the pull request.

For architecture and operational context, start with [docs/README.md](./docs/README.md).
